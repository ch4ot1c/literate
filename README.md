# Learn Coding Fast!

Runs in the browser.

A broad and deep code sandbox, and AI assistant.

#

[Install Node.js](https://nodejs.org/download/release/latest/) (`x64.msi` for Windows, `.pkg` for MacOS, `linux-x64.tar.xz` usually for Linux), then use **Terminal** to install and run it:

```
npm install
npm run dev
```

**Then open:** http://localhost:5137

**Offline Compatible:** Run `.\download_local.ps1` (on Windows) or `./download_local.sh` (on MacOS/Linux), via **Terminal**, to download the in-browser AI Model and Python runner for use locally.

---

http://localhost:5137/_full_notebook.html: The main app - a notebook, sandbox, and editable tutorial builder for JavaScript, TypeScript, JSX/TSX (React), HTML, Python (and pip), and Markdown. Includes an AI assistant.

http://localhost:5137/_ask_ai.html: A simple browser AI chat interface.
